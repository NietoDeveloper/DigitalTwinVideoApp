# Modelo comercial — Software DT

Este documento explica **cómo acceder a la versión real** de Software DT más allá de este showcase público. No contiene precios ni cláusulas contractuales definitivas: es informativo, para que el interesado sepa qué opciones existen y a quién escribir.

## 1. Lo que ves acá (público)

- Demos funcionales con datos ficticios (`apps/client-demo`, `apps/admin-demo`).
- Descripción general de módulos y flujo (`README.md`, `ARCHITECTURE-OVERVIEW.md`).
- Identidad de marca y estética del producto.

## 2. Lo que **no** está acá

- Código fuente de producción (backend real, integraciones, esquemas de base de datos).
- Configuración de infraestructura, credenciales, claves de pasarela de pago.
- Lógica de negocio específica de clientes actuales.

## 3. Modalidades de acceso

| Modalidad | Qué incluye | Para quién |
|---|---|---|
| **Demo guiada** | Recorrido en vivo del producto funcionando, sin acceso a repositorio | Prospectos evaluando la plataforma |
| **Licencia de uso** | Instancia desplegada y configurada para el negocio del cliente (sin acceso al código) | Negocios que quieren usar el producto tal cual |
| **Acceso a repositorio privado** | Colaboración directa con el equipo de Software DT sobre el código real, bajo NDA | Socios técnicos / integraciones a medida |
| **Desarrollo a medida** | Adaptación del Digital Twin (Software DT / DroneDT / EmeraldDT) a un caso de uso específico | Clientes con necesidades particulares de digitalización de procesos |

Los términos, alcance y tarifas de cada modalidad se definen caso a caso con el equipo comercial.
